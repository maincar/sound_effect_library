# 効果音リンク集

無料で使える効果音へのリンクをまとめた静的サイトです。カテゴリ絞り込み・キーワード検索・並び替えに対応しています。

## 仕組み

- 単一の `index.html` で完結する静的サイトです（ビルド不要）。
- 効果音データと広告データは、Google スプレッドシートを CSV としてエクスポートしたものを `fetch` で取得して描画します。
- 各効果音は `?sound=<slug>` のクエリパラメータで個別ページとして表示されます（タイトルと description を動的に書き換え）。

## セットアップ

`index.html` 内の以下の定数を、実際のスプレッドシートに合わせて設定してください。

```js
const SHEET_ID = "ここにスプレッドシートID";
const SHEET_NAME = "シート1";
```

- `SHEET_ID`: データを持つ Google スプレッドシートのID（URLの `/d/` と `/edit` の間の文字列）
- `SHEET_NAME`: 効果音一覧が入っているシート名

スプレッドシートは「ウェブに公開」した状態にし、シートの列は `タイトル, URL, カテゴリ, slug` の順にしてください。

広告用に `ads` という名前のシートも用意し、列は `enabled(ON/OFF), type(feed/bottom), title, image, link` の順にしてください。

## デプロイ

GitHub Pages などの静的ホスティングに `index.html` をそのまま配置するだけで動作します。
